This is where a web server comes in.

A web server is responsible for accepting incoming network connections and handling HTTP communication with clients.

It acts as the boundary between the outside world and the application running on the server.

THE .NET ANSWER

ASP.NET Core applications use Kestrel.

Now the missing piece became clearer.

ASP.NET Core applications use Kestrel as their web server.

Kestrel is responsible for listening for incoming network connections and receiving HTTP requests.

05

WHAT KESTREL DOES

Kestrel receives the request. It doesn't decide what the application should do.

This distinction helped me understand Kestrel's responsibility.

Kestrel handles the web-server side of the communication.

It receives the HTTP request and passes it into the ASP.NET Core application.

It doesn't contain my business logic or decide which controller should handle the request.

INTERVIEW DEPTH

Going one level deeper into Kestrel.

Once I understood Kestrel's basic role. I wanted to understand how to explain it properly in interview.

What exactly is Kestrel?

Kestrel is a cross-platform webserver used by ASP.NET Core applications.

Its responsibility is to handle the web-server side of the communication: accepting network connections, receiving HTTP requests, and sending HTTP responses.

Is Kestrel the same thing as ASP.NET Core?

Is Kestrel the same thing as ASP.NET Core?

No. This distinction is important.

Kestrel Web server
↓
ASP.NET Core Web framework & request pipeline
↓
Application Controllers, services, business logic

Kestrel accepts the network connection and receives the HTTP request. ASP.NET Core then processes that request through its request pipeline.

What happens when a request arrives?

Browser Sends HTTP request
↓ Kestrel ↓ ASP.NET Core Request Pipeline ↓ Endpoint ↓
HTTP Response

Why do we need Kestrel?

An application needs something responsible for the network-facing side of HTTP communication.

The controller or business service should not have to listen for network connections or manage HTTP communication directly.

Kestrel handles that web-server responsibility so that the application can focus on processing the request.

How is Kestrel different from IIS?

Kestrel is the web server commonly used by ASP.NET Core applications. IIS is Microsoft's web server for Windows.

An ASP.NET Core application can run directly on Kestrel, but Kestrel can also be placed behind another web server or reverse proxy such as IIS.
