If .NET is the platform, why do we need ASP.NET Core?

I understood .NET as a general-purpose platform. Then I started wondering what was needed specifically to build web applications.

01

THE QUESTION

What does .NET actually give me?

I had started understanding .NET as the platform underneath applications.

But then another question came to mind:

THE QUESTION

If .NET is general-purpose, how do I build a web applicaiton with it?

02

THE PROBLEM

Web applications have their own problems.

A web application isn't just C# code running somewhere

It needs to deal with things that are specific to the web

HTTP

Receive requests and produce responses.

Routing

Decide which part of the application should handle a request.

Authentication

Determine who the user is.

Authorization

Determine what that user is allowed to do.

03

THE IDEA

What if the web-specific problems had their own toolkit?

Instead of putting every web-specific feature into the general .NET platform, Microsoft built a web framework on top of it.

.NET General platform
↓
ASP.NET Core Web framework
04

ASP.NET CORE

ASP.NET Core is the web framework.

ASP.NET Core provides the web-specific infrastructure needed to build modern web applications and APIs on top of .NET.

This includes the infrastructure for handling HTTP request, routing, middleware, dependency injection, authentication and authorization, along with different ways of building web applications.

05

THE DISTINCTION

C#, .NET and ASP.NET Core are not the same thing.

C# Programming language
↓
.NET Platform
↓
ASP.NET Core Web framework

Understanding this distincition helped me make sense of the different terms I kept encountering in .NET applications.
