So, what exactly is .NET?

I started with C#. Then I realized that understanding the language alone wasn't enough to understand the application I was working on.

01

THE QUESTION

I knew C#. But where does .NET fit?

I initially thought learning C# would be enough to understand the technology behind the application

But while looking at Program.cs, I started noticing things that weren't really explained by C# alone.

That led me to a simple question:

What exactly is .NET?
02

BEFORE .NET

Application development was more fragmented.

Before .NET, Microsoft had several technologies and programming models for building different kinds of applications.

These technologies evolved around different needs and environments, which made the overall development landscape more fragmented.

Microsoft saw an opportunity to provide a more unified programming model and common foundation for application development.

03

THE PROBLEM

Microsoft wanted a common platform.

The problem wasn't that developers couldn't build applications.

Microsoft wanted developers to have a common programming environment and set of services that could be used across different kinds of applications.

The idea was that languages such as C# could work with the same underlying runtime and libraries instead of each language needing completely separate infrastructure.

04

THE SOLUTION

.NET

.NET was Microsoft's answer to this problem: a common platform for building and running applications.

It brought together a runtime, libraries, and development tools that applications could build upon.

05

WHAT DID .NET PROVIDE?

A common set of building blocks.

I started to understand that .NET wasn't simply something that "runs C#".

It also provides libraries, runtime services and development tools that applications can use. 

                            
                                string text = File.ReadAllText("data.txt");

C# gives me the language syntax I use to write this code. But File.ReadAllText() is an API provided by the .NET class libraries.

This helped me understand that C# and .NET are different pieces working together.

06

WHERE DOES C# FIT?

C# and .NET are different things.

This was one of the first important distinctions I had to understand.

C#

A programming language used to write application code.

.NET

A development platform that provides the runtime, libraries and tools used to build and run applications.

07

WHAT DID THIS CHANGE?

C# was part of a larger ecosystem.

I started seeing C# not as the entire technology stack, but as one part of an ecosystem built around the .NET platform.

Developers could write applications using languages such as C# while relying on a common runtime, libraries and tools provided by .NET.

But this answered one question and created another.

If .NET provides the platform, why did Microsoft eventually create .NET Core?
