I started with C#. Then I realized that understanding the language alone wasn't enough to understand the application I was working on.

01

THE QUESTION

I knew C#. But where does .NET fit?

I initially thought learning C# meant learning the technology behind the application

But while looking at Program.cs, I started noticing things that weren't really explained by C# alone.

That led me to a simple question:

What exactly is .NET?
02

BEFORE .NET

Building applications wasn't simple underneath

Before .NET, Microsoft had several technologies, languages and programming models for building applications.

Developers could build applications successfully, but there wasn't one common platform underneath all these different approaches.

This meant that many underlying concerns had to be handled differently depending on the technology being used.

03

THE PROBLEM

Microsoft wanted a common platform.

The problem wasn't that developers couldn't build applications.

The bigger problem was having different languages and technologies working with different underlying models and infrastructure.

Microsoft wanted to provide a common platform underneath them - with common runtime services, libraries and development tools.

C#
Visual Basic
Other .NET languages
↓ Common .NET Platform
04

THE SOLUTION

.NET

.NET was Microsoft's answer to this problem: a common platform for building and running applications.

It brought together a runtime, libraries, developement tools that application could build upon.

C#
↓
.NET
↓
Application
05

WHAT DID .NET PROVIDE?

A common set of building blocks.

I started to understand that .NET wasn't simply something that "runs C#".

It also provides libraries, runtime services and development tools that applications can use. 

                            
                                string text = File.ReadAllText("data.txt");

The C# language give me the syntax to write this code. But File.ReadAllText() is functionality provided by the .NET libraries.

This helped me understand that C# and .NET are different pieces working together.

06

WHERE DOES C# FIT?

C# and .NET are different things.

This was one of the first important distinctions I had to understand.

C#

A programming language used to write the application.

.NET

A development platform and ecosystem that provides the runtime, libraries and tools around the application.

07

WHAT DID THIS CHANGE?

C# became part of a larger ecosystem.

It became part of a much larger ecosystem.

Developers could write applications using languages such as C# while relying on a common runtime, libraries and development environment.

But this answered one question and created another.

If .NET provides the platform, why did Microsoft eventually create .NET Core?
